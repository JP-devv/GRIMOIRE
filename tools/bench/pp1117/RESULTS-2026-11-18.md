# 2026-11-18 -- Flash-Next writing at long context fixed

Branch fast-pp-1117 (Tower repo).  All on the Tower, served, llama-benchy reading (pp) / writing (tg128) tok/s, one
run each.  Build qsal-1118 = 3aabd41 (G31 dev build, image grimoire-b70:v1.10.8 runtime).  Ian's DUAL Flash-Next
profile: 8-bit (--proj int8), two B70s TP, 170 experts a layer in VRAM, GRIMOIRE_PLE_RAM=0, one slot, MTP off.

## Cause (device timeline, 29a5554, token at position >= 60000)
- `.flash` (QSA decode attention, bitmap-masked split-K) = 1,154 us per QSA layer; 12 layers = ~14 ms of the token.
  It walked every key of its split; each selected 4-key block cost 256 dependent K loads one cache row apart.
- PLE layer = 1.9 ms a token at every context: 16 table rows read one after another from /mnt/models (USB SSD).
- `.ix-topk` 110 us, `.ix-prep` 119 us, `.ix-logits` 52 us (each incl. marker overhead).

## Fix (34f0487, 6241b0b, 3aabd41)
- attention.cpp `flash_decode_qsa_list`: a split takes a slice of the selected block list; per block all 16 lanes load
  their 16 dims of the 4 keys + V rows at once.  Same keys; summation order differs.  GRIMOIRE_QSA_LIST=0 = old.
- ops.cpp top-k: one SLM atomic per distinct bin per sub-group (same selection).  GRIMOIRE_QSA_TOPK_AGG=0 = old.
- PLE file rows: up to 16 reads in parallel.

## One-card Qwen writing: where the step goes (build tl2-1117, Swift INT4, MTP K4, pp512 tg256)
- GRIMOIRE_BATCH_HOST_TIMING: the host enqueues a verify step in ~3.2 ms, then waits ~28.7 ms -> device-bound.
  Step: draft 3.1-3.2 ms, verify 31.9-32.0 ms (4.9-5.2 rows), commit 1.1 ms; 3.1-3.4 tokens a step.  Plain decode
  (no MTP) 35.2 tok/s = 28.4 ms a token.
- GRIMOIRE_TIME_LAYER (verify steps, medians, each incl. ~8 us drain): DeltaNet layer 4: qkv 67, z 45, norm+out 51,
  gate_up 179, down 121, small ops (norms, conv, gates, recurrence, swiglu) ~107 us; attention layer 3: q 75, kv 29,
  rope+kv 18, flash 36, o 54, gate_up 183, down 119.  Weight-read floor ~330 / 310 us a layer; FFN down at 5 rows runs
  ~72% of 602 GB/s.
- urakozz (their BENCHMARKS.md): plain step 29.4 ms, verify at 4 rows 33.3 ms -- the same as ours.  Their llama-benchy
  "121" is the median of 101 / 121 / 138 (`--pp 128 --tg 128 --depth 0 32768 --exact-tg --runs 3`), from prompt
  lookup on llama-benchy's repeating text (72.5 before it); at 32K they have 61, we 82-99.
