# K8/V4 host scalar reference (D=256, one KV head shared by six Q heads)

Host-only fixture for the K8/V4 KV cache layout and its quantized causal GQA
path: `D = 256`, `GQA = 6`, **one** KV head per rank with six Q heads on it, an
int8-K / int4-V page in the documented region order, and a kernel-shaped
attention path compared against two independently wired scalar references.

No SYCL, no GPU, no vLLM, no checkpoint weights, no engine execution. Nothing
from the reference package is run: `layout.py`, `oracle.py` and
`xe2_kv_ops.cpp` were **read** and their rules reimplemented here.

Run from the GRIMOIRE root with a host compiler:

```sh
(
    set -eu
    exe=$(mktemp /tmp/test_qfn_k8v4.XXXXXXXX)
    trap 'rm -f "$exe"' EXIT
    c++ -std=c++17 -Wall -Wextra -Werror \
        regressions/2026-11-19-qfn-k8v4/test_qfn_k8v4.cpp -o "$exe"
    "$exe"
)
```

Exit status is 0 only when every check passes; the fixture prints one
`PASS`/`FAIL` line per assertion plus `MEASURED` rows for the numbers it
observes.

## Documented (taken from the reference package, not executed here)

From `qfn-enhanced/k8v4.md` section 2, `k8v4_v030/layout.py`,
`k8v4_v030/oracle.py` and `k8v4_v030/native/xe2_kv_ops.cpp`:

- `PAGE = 64`, `D = 256`, `GQA = 6`, `V4_COLS = 128`, `SCALE_BYTES = 4`,
  `SLOT_BYTES_PER_HEAD = 396` (`256 int8 K + 128 packed int4 V + 3 x 4 B fp32`).
- Page region order is region-major: `K, V, k_scale, v_scale, v_zero`, with the
  region views strided so that a page stride skips the other regions. TP2
  (`hkv = 2`) is 50,688 B per page / 792 B per token; the single-GPU
  (`hkv = 4`) layout is 101,376 B / 1584 B.
- `PageLayout` accepts `hkv` of 2 or 4 only, and `for_heads()` demands
  `num_heads == 6 * num_kv_heads`.
- K is symmetric int8: `scale = amax/127` (0 for an all-zero row),
  round-half-away-from-zero, clamp +-127.
- V is affine int4: `scale = max((hi-lo)/15, 1e-8)`,
  `zero = clamp(floor(-lo/scale + 0.5), 0, 15)`,
  `nibble = clamp(floor(v/scale + zero + 0.5), 0, 15)`, byte
  `= even_dim | odd_dim << 4`, i.e. the **even dimension in the low nibble**.
- Scores are `int8 dot * q_scale * k_scale / sqrt(256)`.
- In the paged decode kernel the int8 dot is computed for all 64 page tokens
  and only then overwritten with `-INFINITY` when `tok >= n_valid` or
  `k_abs >= q_end`; V rows with `tok >= n_valid` are zero-filled before PV so a
  poisoned masked row cannot inject `0 * NaN`. Probabilities pass through fp16,
  the PV accumulator is fp32, and the three affine tensors are fp32.
- `visible_lens(seq_len, q_len)` gives the per-query causal ends, index 0 being
  the longest, each clamped at 1, with `q_len` limited to the 10-token packed
  decode tile.

## Assumed here (called out in the output)

- **`hkv = 1`.** The shipped `PageLayout` refuses `hkv = 1`, so a TP4 slice
  (two KV heads, each replicated on two ranks, with six Q heads per rank)
  cannot be described by it. This fixture applies the
  documented per-head formulas with `hkv = 1` (396 B per token per head, page
  25,344 B) as an extrapolation, and asserts the documented refusal separately.
- Row data is generated by a local SplitMix64, so the fixture does not reproduce
  the package's `random.Random` rows.
- Tolerances are derived bounds, printed next to the measured number.

## What is checked

- Page geometry, refusals, region offsets/lengths/alignment, exact region
  tiling, and that memory order `[token, head, cell]` (`hkv*D` per token, 512 B
  at TP2) is *not* the logical `[head, token, 396]` order.
- K/Q scale = `amax/127`, the amax lane reaching +127, the +-127 clamp driven by
  an injected under-estimated scale (it is unreachable through `amax/127`), an
  all-zero K row (scale 0, codes 0, no NaN), and the exact tie row where the
  documented half-away rule and the source's `sycl::rint` disagree.
- V: known nibble packing on an integer ladder, the 1e-8 scale floor, a flat
  positive and a flat negative row (both saturate and lose ~0.5 absolute), and
  the documented open edge case -- an all-negative spread row whose raw
  zero-point (150) clamps to 15 and destroys the row.
- fp32 metadata: a 1e-7 scale survives the page bit for bit, and the same value
  would change through fp16 (the reason the region is 4 B).
- Attention at `seq_len = 137`, `q_len = 3`: fp64 reference vs a kernel-shaped
  path (fp16 page probabilities, fp16 dequantized V, fp32 partials merged with
  M/L rescaling), vs an independently wired BF16 reference, plus causal
  boundary, softmax shift invariance vs an unshifted overflow, single-token
  identity, zero-K uniform attention, and int8 dot headroom for `D = 256`.
- Mutable prefix/tail validity: pages of 64/64/9 for 137 tokens, a masked tail
  poisoned with NaN/inf scales, 0xFF nibbles and 0x7F K bytes changing the
  result by exactly zero, a live-row poison as the negative control, and the
  boundary tested from both sides (page 2 row 8 = token 136 moves the answer,
  row 9 = token 137 does not).
